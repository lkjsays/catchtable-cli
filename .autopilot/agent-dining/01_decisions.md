# 결정
- 시스템 신뢰 저장소를 사용하는 SSLContext를 httpx에 명시적으로 전달한다. 전역 monkeypatch나 verify=False를 사용하지 않는다. 명시적인 CA 환경 변수는 존중한다.
- 예약 생성은 모호한 응답 후 자동 재시도하지 않는다. 공개 웹앱 계약을 확인하고 실제 예약 대상·확인 정보가 있을 때만 실행 가능하도록 한다.
- 실제 예약 검증은 로그인과 특정 예약 요청이 없으므로 수행하지 않는다. 이 한계를 문서화하고 공식 예약 화면으로 이어지는 경로를 제공한다.

- 시간 조회는 issue-key 공개 키와 c1~c4를 사용해 RSA PKCS#1 v1.5로 암호화한다. 실제 응답으로 검증했다.
- 직접 예약 create는 holdings/form/menu/payment/terms 계약이 확인되지 않은 상태에서 노출하지 않는다. 기존 불완전 reserve 메서드는 명시적 오류로 바꾸고 CLI는 공식 화면 연결을 제공한다. 요청 전체를 자동 예약 완료로 판정하지 않는다.
- OS 저장소의 인증은 명시적인 환경 변수보다 낮은 우선순위이며 기본 공식 API 주소에만 자동 적용한다. 실제 저장은 사용자가 입력한 쿠키가 유효한지 서버 확인 후 수행한다.
- 원래 설치된 ct가 같은 저장소 editable 설치임을 확인했다. `uv tool install --editable /Users/kjlee/Projects/catchtable-cli --reinstall`로 해당 도구 환경만 갱신했다. 다른 도구 환경은 변경하지 않았다.
- 최신 Typer는 Click를 전이 의존성으로 설치하지 않아 스키마가 깨졌다. 공개 파라미터 메타데이터를 읽도록 수정하고 두 환경에서 검증했다.
