# 목표
일반 실행에서 TLS 검증을 유지하며 실제 조회가 가능하고, 에이전트가 식당 검색·근거 있는 추천·예약 시간 확인·예약 진행을 수행할 수 있게 한다.

# 범위와 권한
사용자가 자율 구현을 위임했다. 코드/문서/로컬 검증/공개 읽기 API는 실행한다. 실제 예약 생성·결제·약관 동의는 이번 개발 검증에서 실행하지 않는다. 사용자가 식당·일시·인원·조건을 정하지 않았으므로 임의 예약을 만들 수 없다. 인증은 존재 여부만 점검하며 비밀값을 출력하지 않는다.

# 실행 방식
같은 세션에서 구현 및 검증. 외부 인증을 요구하는 단계는 구현·오프라인 검증과 실계정 검증을 구분한다. 일반 검색/추천은 무인증으로 실제 검증한다.
